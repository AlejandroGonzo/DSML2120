
# Data Science & Machine Learning Portfolio

Welcome to my data science portfolio!

I'm Alejandro Gonzalez, a Data Science and Machine Learning student at Metropolitan State University of Denver.

This repository contains my data visualization projects, interactive dashboards, and coursework developed using Python and Streamlit.

## Featured Project: Colorado Electricity Grid Analysis

For DSML2120 Project 2, I analyzed 8,760 hourly electricity observations from the EIA-930 dataset for the Public Service Company of Colorado (PSCO).

The project explores electricity demand, seasonal patterns, and electricity generation from different energy sources.
